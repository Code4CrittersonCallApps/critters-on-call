“Make a hoop, secure the caboose.”

Mnemonic + textbook containment. Same steps for helpers, member gifts, and field ops — voice differs; motion does not.

Four beats

  • 01 Cue — say the rhyme before child contact or handoff
  • 02 Hoop — calm closed boundary (arms/body/pen edge), never a squeeze
  • 03 Caboose — chest/shoulders and hindquarters before lift/pass
  • 04 Reset — staff retain control; struggle → re-hoop or return to pen

Hard stops

  • Never lift by tail, ears, horns, neck, or legs
  • Stop if animal or child is distressed
  • No chasing · no dangling · no one-handed wing/ear grabs
  • Event pens: kids generally do not enter

Species notes

  • Goats: scoop chest + hind · latch pens
  • Bunnies: never ears/scruff-only · rear-feet set-down
  • Birds: both hands — wings tucked, feet supported
  • Babies: small fencing · hoop at pen edge before lift

Incident playbooks

Running late

  • After pickup: text the chain with Ann-Marie + Michael immediately — don’t wait until you’re almost there.
  • Have the venue address in the thread (copy from calendar) so anyone can nav-help or call the host.
  • Communicate ETA + reason in one short text (traffic / load / animal reset). Update if ETA slips again.
  • Host call: if >10–15 min late, one of AM/Michael or you (if asked) rings the booker with the new ETA.
  • On arrival: calm setup — mobility over fancy; apologize once, then deliver.
  • Stub expand: rain delay script · multi-helper relay · customer credit ownership.

Animal escape · STUB

  • Stop the crowd calmly · one person tracks · hoop/caboose on recapture · count inventory before reopen.
  • Text AM/Michael if off-property or longer than a minute. Stub: species-specific notes.

Kid scare / distress · STUB

  • Return animal to pen · soft voice to child + guardian · no blame · offer reset or different animal.
  • If bite/scratch: first-aid + notify AM/Michael + host. Stub: incident form path.

Weather · STUB

  • Lightning / severe: animals secured, people to cover, pause petting. Shade-first; tarp/hay as needed.
  • Text chain if cancel/shorten. Stub: heat index / cold thresholds.

No-show (helper or host) · STUB

  • Helper no-show: backup list → owners cover → notify booker if delayed.
  • Host no-show / locked site: text AM/Michael · wait window · photo proof · don’t leave animals unattended. Stub: billing ownership.
