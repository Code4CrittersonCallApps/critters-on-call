IQ Test Prep: One-Page Cheat Sheet

Michael Sheehan · companion to IQ_PREP_COURSE.html · 19 Oct 2026

Spatial (your main lever)

  • Rotated vs mirrored: pick two anchor features; walk clockwise naming them. Same order = rotation, reversed = mirror.
  • 3D cubes: encode arms in words (“3, turn, 2, turn, 2”); same sequence first, then the hand rule on the last turn. Rotate the short way.
  • Paper folding: unfold last fold first; mirror every hole across each crease; one layer under the punch = one hole.
  • Cube nets: run of three = ends opposite; zig-zag = skip-one opposite. Opposites never show together. Check corner order and which edge an arrow points to.
  • Block counting: column heights from top faces, then add. Every raised block needs support. Painted n³: 3 faces 8 · 2 faces 12(n−2) · 1 face 6(n−2)² · 0 faces (n−2)³.
  • Views: stand at the arrow, name your left and right. Front = tallest stack in each line of sight. Top = footprint. Opposite side = left-right flip.
  • Cross-sections: sides = faces the plane crosses (cube: 3–6). Parallel faces give parallel sides. Cylinder: circle, ellipse, rectangle. The drawing is in perspective; answer from the solid.
  • Embedded figures: hunt the rarest feature first; same size and orientation; one missing edge = reject.
  • Block design: grid the design first; corner, edge, middle; turn the block to find the face. Visual puzzles: area check, then the most awkward piece; no flipping.
  • Maps: heading as quarter-turns (R +1, L −1, about +2). Rotated map: page bearing minus the north arrow's angle.
  • Patterns: test mirror symmetry and repeating tiles; predict the patch, check all four neighbours.
  • Stuck? Switch from imagining to a rule: chirality walk, opposite faces, layer count.

Fluid / matrices

  • List attributes: shape, number, size, shade, position, orientation, lines.
  • One rule per attribute; rows, then columns, then diagonals.
  • Rules: constant, progression, each-value-once, add/subtract/XOR overlays, rotation.
  • Predict the cell before reading options. Two survivors = a missed rule.
  • Figure weights: convert to the lightest shape, one scale at a time.
  • Odd figure: count sides, dots, lines, symmetry before looks.

Verbal

  • Say the relation as a sentence; test each option; tighten if two fit.
  • Watch direction, part of speech, and “lack of” (craven : courage).
  • Similarities: the most general category true of both. Never a difference.
  • Key the standard meaning, not the clever one.

Numerical

  • Series: differences → 2nd differences → ratios → split odd/even → squares, cubes, primes, Fibonacci → alternating ops.
  • Rates add, times don't. Percents multiply. Equal-distance average speed is below the simple mean. n gaps need n + 1 posts.
  • Estimate first, plug the answer back in.

Logic

  • Syllogism: try to build a counterexample world. Two negatives = no conclusion.
  • P → Q gives not-Q → not-P only. “A only if B” = A → B. “A unless B” = not-B → A.
  • Seating: fixed facts, then pairs, then negatives; fix one seat at round tables; recheck every clue.

Working memory

  • Chunk 3-3-2. Rehearse in the same rhythm.
  • Backward: reverse inside chunks, say chunks last-first.
  • Sequencing: tick a mental number line; keep duplicates. Letter-number: numbers first, then letters.
  • Running span: rolling window of the last four.

Processing speed

  • Learn the key in row one. Steady pace; no erasing; never skip.
  • Symbol search: distinctive part first; orientation decides; one scan per target.

Test day

  • Budget = time ÷ items (Wonderlic about 14 s; Mensa Norway about 43 s, harder later). Checkpoints at ¼, ½, ¾.
  • No penalty on most tests: never leave a blank. At 2× budget with no rule, guess, flag, move.
  • One-to-one tests: you can't skip; always give a reasoned answer.
  • Sleep a normal night; no cramming. Caffeine: usual dose, usual time.
  • Nerves = readiness. One slow breath after a hard item; each item is one point.
  • Eat, glasses, arrive early. Practice removes avoidable losses; it doesn't change g.
